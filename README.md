# さぁジャッジ！

> クイズでカードゲームのルールを楽しく覚えられるサイト

🌐 **https://sirjudge.com/**

---

## 概要

**さぁジャッジ！** は、ポケモンカードゲームなどのトレーディングカードゲームのルールを、◯✕クイズ形式で楽しく学べるWebアプリケーションです。

### 特徴

- 🎴 **◯✕クイズ形式** — シンプルな操作でルールを学べる
- 🎮 **2つのモード** — 「ふつうにジャッジ」（出題数固定）と「れんぞくジャッジ」（連続正解チャレンジ）
- ⚙️ **カスタマイズ設定** — レギュレーション・難易度・出題数を自由に設定
- 📱 **レスポンシブ対応** — スマホ・タブレット・PCで快適に利用可能
- 🔤 **ルビ（ふりがな）表示** — 子どもでも読みやすい
- 📤 **SNS共有** — 結果をXで共有・テキストコピー

## ページ概要

### トップページ（`/`）
ゲームタイトルの一覧から、覚えたいカードゲームを選択するエントリーポイント。

### モード選択（`/games/pokemon/`）
クイズのモードを選択する画面。

| モード | 内容 |
|--------|------|
| **ふつうにジャッジ** | 設定した問題数（デフォルト10問）をランダム出題。正答率が表示される |
| **れんぞくジャッジ** | 不正解になるまで出題が続く。連続正解数を競うチャレンジモード |

### クイズ画面（`/games/pokemon/ox/`）
問題が出題され、◯（正しい）か ✕（間違い）で回答。回答後に正解・解説が表示される。

### 設定（`/games/pokemon/settings/`）
クイズの出題条件をカスタマイズできる画面。

| カテゴリ | 設定項目 | 選択肢 | デフォルト |
|---------|---------|--------|-----------|
| 出題設定 | レギュレーション | すべて / スタンダード / エクストラ / 殿堂 | すべて |
| 出題設定 | 難易度（複数選択可） | かんたん / ふつう / むずかしい | 全選択 |
| 出題設定 | 出題数 | 5 / 10 / 15 / 20 問 | 10問 |
| 表示設定 | ルビ表示 | ON / OFF | ON |
| 表示設定 | 自動スクロール | ON / OFF | ON |

## デザインシステム

### カラーパレット

| 用途 | カラー |
|------|--------|
| アクセント | `#f9c9c9` |
| カード背景 | `#fff` |
| テキスト | `#222` |
| 補助テキスト | `#6b7280` |
| 正解 | `#10b981` |
| 不正解 | `#ef4444` |
| ダーク背景・強調 | `#111827` |
| ボーダー | `#E5E7EB` |

### UIコンポーネント
- **ボタン**: pill型（`border-radius: 9999px`）、drop-shadow 付き
- **カード**: 角丸16px、1px border + box-shadow
- **トグルスイッチ**: カスタムCSS（チェック時: 緑 `#10b981`）
- **トースト通知**: 画面下部中央、2秒後自動消去
- **確認ダイアログ**: カスタムオーバーレイ
